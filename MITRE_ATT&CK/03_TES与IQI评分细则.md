# [3] TES 与 IQI 评分细则

## 一、TES（Total Evaluation Score，总评测分）【官方】

```
TES = DQI（检测质量指数，0–1）+ PQI（防护质量指数，0–1）
范围 0.0–2.0，也可换算为 0–100%

分数后面括号里有一个"修饰符"，说明这个分数是谁做出来的：
  自动化平台 / 人工分析师（服务团队）/ AI 辅助 / 混合
```

## 二、DQI（Detection Quality Index，检测质量指数）【官方，具体权重未知】

| 组成 | 含义 |
|---|---|
| 覆盖度 | 每个技术的告警带了多少上下文 |
| 精度 | 能否避免误报，能否把零散告警合并成一个事件 |
| 速度 | 平台检测有多快；**人工分析师上报的时间不计入** |

## 三、PQI（Protection Quality Index，防护质量指数）

- 重点看阻断时机。【官方】
- 越早阻断分数越高。【推断】未见原文表述。

## 四、IQI（Investigation Quality Index，调查质量指数）【待核实】

- 官网首页出现过这个名称，对应的问题是：**在第一条告警之后，分析师能否还原攻击者的全部活动范围，并得出站得住脚的结论？**
- 但首页标签明显错位（检测标成 PQI、防护标成 IQI、调查标成 ACW），而方法页的公式里只有 DQI + PQI。
- 三种可能，目前没有证据区分：
  1. IQI 是单独报告的指标，不计入 TES；
  2. IQI 是后来加入的，公式有更新；
  3. 只是首页的排版错误。

## 五、理解要点【推断】

1. **同分不同义**：一个 1.6（平台自动完成）和一个 1.6（人工分析师完成），意味着不同的运营成本和规模化能力。比较时必须连同修饰符一起看。
2. **加权放大场景影响**：按技术重要程度加权，场景选择对总分的影响会被放大。
3. **总分掩盖结构**：DQI 0.9 + PQI 0.5 与 DQI 0.5 + PQI 0.9 都是 1.4，但前者偏检测、后者偏阻断。要拆开看。
